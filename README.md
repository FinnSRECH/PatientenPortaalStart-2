# MijnZorg - Patientenportaal starter

Eerste iteratie van de ziekenhuiscasus in ASP.NET Core Razor Pages (.NET 8).

## Starten in Visual Studio
1. Open `Hospital.PatientPortal/Hospital.PatientPortal.csproj` in Visual Studio 2022.
2. Zorg dat de .NET 8 SDK / ASP.NET workload is geinstalleerd.
3. Start met HTTPS.
4. Demo-login: `jan@demo.nl` / `Welkom123!`.

## Wat werkt al
- Cookie-authenticatie
- Registreren
- Inloggen/uitloggen
- Persoonlijk dashboard
- Klacht registreren en eigen klachten bekijken
- Eigen planning bekijken
- Contactgegevens wijzigen
- In-memory data (bewust: persistence is niet verplicht in de opdracht)

## Volgende bouwstap
Behandelingen, documenten, evaluaties, consultatiehistoriek en auditlogging toevoegen.
